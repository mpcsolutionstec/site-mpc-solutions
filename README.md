# MPC Solutions — site institucional

Site institucional responsivo da MPC Solutions, feito com HTML, CSS e JavaScript puros para publicação no GitHub Pages.

## Publicar no GitHub Pages

1. Envie os arquivos desta pasta para a raiz do repositório (ou configure o Pages para usar esta pasta).
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**, escolha a branch e a pasta (`/root` ou `/docs`) onde está o `index.html`.

## Formulário de contato

O formulário usa o serviço FormSubmit (`formsubmit.co`) para encaminhar mensagens a `mpcsistema669@gmail.com`, sem precisar de servidor próprio. Na primeira mensagem enviada pelo formulário, o FormSubmit enviará um e-mail de ativação para esse endereço. Confirme essa ativação para liberar os envios seguintes. Como é um serviço externo, o funcionamento depende da disponibilidade e das regras do FormSubmit.

## Arquivos

- `index.html`: conteúdo e estrutura da página.
- `styles.css`: identidade visual e layout responsivo.
- `script.js`: menu móvel e ano automático no rodapé.
- `assets/images/`: logo e imagens dos projetos fornecidas.
